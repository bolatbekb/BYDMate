## Что нового в 4.4.1.18

- **Свои значки манёвров на лобовом стекле (HUD).** Нарисован новый набор из 43 стрелок под проекцию на стекло:
  - светлые голубые, без тёмно-синего, который днём на стекле тускнеет;
  - чёткие края, соседние дороги серым;
  - номер съезда с кольца в углу;
  - отдельные значки для колец с левосторонним движением;
  - новый флаг финиша.
- **Включается в настройках:** «Дисплей» → «Проекция на лобовое (HUD)» → «Использовать свои иконки для навигатора». По умолчанию выключено, всё работает как раньше. Если для манёвра нового значка нет, показывается прежний значок BYDMate, а если нет и его, то картинка навигатора.

### После обновления
Чтобы попробовать новые значки, включите настройку. «Проверка HUD» тоже покажет новый значок.
